01//The loop

Replaces human-latency Build-Measure-Learn

Specify. Verify. Falsify.

Once Build is nearly free, the bottleneck moves to the speed at which an artifact can be trusted, and to the speed at which a person can decide what is worth building.

S / 01

Specify

Before any agent writes code, state the outcome, the invariants that must hold, the failure modes that matter and the stop conditions, in a form a machine can check.

Gate: spec validated against schema

V / 02

Verify

Check every artifact with mechanisms that do not trust the producer. Formal proofs where the property admits one, deterministic tests where it does not, adversarial review for the rest.

Gate: independent check, bound to the artifact hash

F / 03

Falsify

Each cycle tries to break the claim. Ask which assumption, if false, would change the decision. Negative and inconclusive results are kept, so no one repeats a failed search.

Gate: result recorded, including failure

Falsify←returns to Specify with the next question

02//Swarm architecture

Role separation is the main control

No persona both produces and approves its own output.

The swarm is a set of bounded agent personas. Each has one responsibility, a defined permission set and an output contract.

Every handoff carries the specification version and the artifact commit hash. A handoff without a hash is invalid.

P-01

Architect

Owns the specification: outcome, interfaces, invariants, decomposition.

write spec and design record · no production code for components it will review

P-02

Kernel engineer

Implements against the spec in the target runtime. Produces code, build files and tests.

write assigned component and branch · cannot merge

P-03

Adversarial auditor

Constructs failure cases, trust-boundary violations and specification drift. Finds what the engineer missed.

read artifact and spec · files findings only

P-04

Formal mathematician

States and checks invariants, bounds, termination and equivalence. Reports what it could not formalize.

produce machine-checkable proofs, Lean 4 where applicable

P-05

Integration owner

A human. Holds merge authority, resolves persona disagreements and records decisions.

decide · never delegated to an agent

03//Verification standard

A claim is accepted only at the level it asserts

Four levels of evidence.

0observed

Seen once

A behavior was observed. Not evidence of reliability.

1tested

Reproducible test

A reproducible test passes at a recorded commit, with stated coverage.

2audited

Attempted falsification

An independent persona tried to break the claim. Attempts and outcomes are recorded.

3proven

Machine-checked

A proof, Lean 4 where applicable, covers the stated property under stated assumptions.

A test pass is never described as proof of a property it did not check.

04//Principles

P1 to P11

Eleven working rules.

  1. P1

    Specification precedes generation.

    No agent produces an artifact without a written, checkable statement of what it must and must not do.

  2. P2

    Trust is not delegated to the producer.

    Independent checks run in an environment the producer cannot alter.

  3. P3

    Determinism is a feature.

    Same inputs, same outputs. Non-determinism is a defect to isolate and explain.

  4. P4

    Invariants beat heuristics.

    Where an invariant can be stated, check it. Heuristics are labelled as such.

  5. P5

    Authority stays with a named human.

    Agents act within bounded permissions. Consequential and irreversible actions need a recorded human decision.

  6. P6

    Cost includes checking.

    Production, review, verification, repair and maintenance all count toward the true cost.

  7. P7

    Sovereignty over the stack.

    For high-assurance work, control the hardware, runtime and trust boundaries. Document any opaque dependency.

  8. P8

    Tribute is paid through falsification.

    Honor the lineage of mathematics and science by checking classical intuitions over exact arithmetic (Q or Z) against adversarial nulls. Not through hagiography, folklore or vanity memorials.

  9. P9

    Novelty is tiered and quarantined.

    Prior art is N0 and is cited, not claimed. Incremental advances are N1 and scoped to their exact reach. N2, "The Theorem", waits for complete machine-checked formalization: zero sorry, zero axiom, zero cheat.

  10. P10

    Pre-registered falsification and public retraction.

    Hypotheses and falsification criteria are fixed before the run. A hypothesis that collapses under null-normalization is published as a result. Retraction is a victory of the method over ego.

  11. P11

    Naming restraint.

    No legendary names, and no breakthrough claims on placeholders, before the formal proofs exist.
