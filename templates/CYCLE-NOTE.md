# Cycle note

Use the useful fields in an existing issue or work record. Omit fields that do not affect the decision. This is not an extra approval ceremony.

- **Problem and intended people:**
- **Accountable owner / decision authority:**
- **Existing work and canonical home:**
- **Evidence so far:** observations with sources; interpretation; assumptions; contrary evidence.
- **Question / falsifiable hypothesis:**
- **Baseline and comparison limits:**
- **Smallest useful test / deliverable:**
- **Primary outcome:** denominator, period, rubric and decision threshold.
- **Quality, safety and privacy guardrails:**
- **Scope and authority:** allowed actions, data, recipients; approvals still needed.
- **Resources and stop conditions:** time, spend, parallel work and review capacity.
- **Delegation / handoff:** owner of each distinct part, inputs, output contract and integration owner.
- **Open choices:** temporary default, reversal cost, trigger, latest safe point and owner.
- **Result:** exact artifact/configuration, source evidence, failures, costs, passed/failed/blocked/untested checks.
- **Decision:** continue, change, stop or inconclusive; rationale and decision-maker.
- **Next step / revisit trigger:**
- **Reusable lesson:** what changed, where it belongs, and evidence status.
